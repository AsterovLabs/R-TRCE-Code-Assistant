# Brand assets

Both SVGs are copied verbatim from the Asterov Labs design system
(Fleet Suite apps/website/public/) so the Studio speaks the same visual
language as the rest of the ecosystem:

- `asterov-icon.svg` - the Asterov "A" monogram (rounded frame + mauve/blue/teal
  gradient stroke + pulsing accent dot). Used in the Studio title bar and favicon.
- `favicon.svg`    - the same mark without the inner inset, sized for tab icons.

Palette: Catppuccin Mocha (base #1e1e2e, crust #11111b) with the accent gradient
#cba6f7 -> #89b4fa -> #94e2d5. Keep these in sync with www/rtrce-theme.css.
